# Παιδική Παράσταση

Offline συνοδός του πραγματικού επιτραπέζιου παιχνιδιού, για 2–6 παίκτες.

## Άνοιγμα

Ανοίξτε το `dist/Paidiki_Parastasi.html` σε σύγχρονο browser. Περιλαμβάνει όλη την εφαρμογή,
τις 300 εικόνες καρτών και τα τρία σκηνικά ImageGen. Δεν χρειάζεται server ή σύνδεση.
Η πρώτη επίσκεψη χρησιμοποιεί το θέμα «Απλό & Καθαρό».

## Build

Απαιτείται Node.js 22 ή νεότερο. Δεν απαιτούνται πακέτα npm.

```sh
node scripts/build.mjs
```

Το build δημιουργεί το αυτοτελές `dist/Paidiki_Parastasi.html` και το αντίγραφο `dist/index.html`
για GitHub Pages. Κάθε ένα λειτουργεί ανεξάρτητα.

## Παιχνίδι

Ο παίκτης αγγίζει το ίδιο το ζάρι για να το ρίξει με ήχο κύλισης, μετακινεί το φυσικό του πιόνι στο πραγματικό ταμπλό, επιλέγει το
χρώμα της θέσης, παίρνει κάρτα και επιλέγει «Τέλος σειράς». Η εφαρμογή δεν γνωρίζει τη θέση
του πιονιού και δεν προσθέτει σκορ, χρονόμετρο ή επιπλέον κανόνες.

Κάθε κατηγορία περιλαμβάνει τους 100 αρχικούς ελληνικούς τίτλους. Οι κάρτες δεν επαναλαμβάνονται
μέχρι να εξαντληθεί η συγκεκριμένη τράπουλα. Στην επόμενη επιλογή της εξαντλημένης κατηγορίας,
όλες οι κάρτες της γίνονται ξανά διαθέσιμες. Οι άλλες κατηγορίες διατηρούν την πρόοδό τους.

Η πρόοδος, ο ενεργός παίκτης και η τρέχουσα κάρτα αποθηκεύονται τοπικά. Οι ρυθμίσεις επιτρέπουν
άμεση αλλαγή μεταξύ τεσσάρων θεμάτων, πέντε εμφανίσεις ζαριού (του θέματος, κόκκινο με άσπρες κουκκίδες, κλασικό, μπλε και ξύλινο) και επιβεβαιωμένη επανεκκίνηση. Το θέμα και η εμφάνιση ζαριού διατηρούνται ανεξάρτητα. Ο ήχος παράγεται τοπικά με Web Audio, χωρίς λήψεις.
Αν ο browser απαγορεύει την τοπική αποθήκευση, το παιχνίδι εξακολουθεί να λειτουργεί όσο η σελίδα
παραμένει ανοιχτή. Το σχετικό μήνυμα εμφανίζεται στις ρυθμίσεις.

## Πηγαίος κώδικας

- `src/`: δομή, responsive CSS, θέματα, αποθήκευση, λογική παιχνιδιού και πραγματικό CSS 3D ζάρι.
- `assets/cards/`: 300 βελτιστοποιημένες εικόνες WebP, ελληνικές λεζάντες και πλήρη prompts.
- `assets/themes/`: τρία πρωτότυπα σκηνικά ImageGen, βελτιστοποιημένα WebP και prompts.
- `Paidiki_Parastasi.prototype.html`: αμετάβλητο αρχικό πρωτότυπο.
- `scripts/build.mjs`: build χωρίς εξωτερικές εξαρτήσεις, με έλεγχο διατήρησης της αρχικής τράπουλας.
- `tests/`: έλεγχοι λογικής και αυτοματοποιημένοι έλεγχοι browser.

Οι 300 εικόνες δημιουργήθηκαν με το ενσωματωμένο ImageGen. Περιλαμβάνονται τα 10 αρχικά
επιλεγμένα δείγματα και οι 290 επόμενες εικόνες. Οι λεζάντες είναι κανονικό ελληνικό κείμενο.
Τα σκηνικά είναι νέα έργα και δεν αποτελούν screenshots των mockups. Τα UI icons και τα πιόνια
χρησιμοποιούν SVG, ενώ το ζάρι έχει έξι πραγματικές CSS 3D επιφάνειες με αντίθετες πλευρές που αθροίζουν 7.

Το παιχνίδι σχεδιάστηκε για portrait κινητά και οριζόντιο desktop. Η κανονική οθόνη παιχνιδιού
δεν χρειάζεται κύλιση. Στην προβολή κάρτας σε όρθιο κινητό η εικόνα αξιοποιεί όλο τον διαθέσιμο χώρο και η περιοχή ζαριού συμπτύσσεται. Σε οριζόντιο κινητό υπάρχει λειτουργική εναλλακτική διάταξη και υπόδειξη
για κατακόρυφη χρήση. Η αρχική οθόνη και οι ρυθμίσεις επιτρέπουν κύλιση όταν χρειάζεται.

Οι έλεγχοι σε πραγματικό iPhone Safari πρέπει να γίνουν επιπλέον της προσομοίωσης viewports στον browser.
